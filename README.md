# Aumenta ou Paga pra Ver

Jogo de cartas e blefe para dois a seis jogadores, com adversários automáticos e suporte a instalação no celular.

Abra `simulador.html` no navegador para jogar. Para testar instalação e funcionamento offline, sirva a pasta por HTTPS ou em localhost, por exemplo com `python -m http.server 8000` e acesse `http://localhost:8000/`.

Para publicar gratuitamente no GitHub Pages, em **Settings → Pages**, selecione **Deploy from a branch**, a branch `main` e a pasta `/ (root)`. No plano GitHub Free, o repositório precisa ser público. O endereço esperado é `https://marcosvba.github.io/LiarsDeck/`.

As regras estão em `regras-finais.md`. Os nomes são armazenados no navegador do próprio dispositivo.
