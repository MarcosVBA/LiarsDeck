# Aumenta ou Paga pra ver

- Baralho de 56 cartas (dois coringas)
- Cada jogador pega 5 cartas (para 4 jogadores, pegue 4 cartas para até 6 jogadores)
- O jogador que embaralhou deve fazer uma aposta, após analisa sua mão
	- Diga um naipe e uma quantidade de cartas
	- O próximo jogador deve aumentar a aposta ou duvidar
		- Se duvidar, todos mostram a mão e contam a quantidade de cartas do naipe em questão
			- Ao acertar: O jogador que fez a aposta deve revelar uma carta para cada derrota até o final do jogo
			- Se errar: O jogador que duvidou recebe a mesma penalidade

- Algumas cartas de face podem ser adicionadas para adicionar habilidades secretas aos jogadores (durante sua vez de apostar, aumentar ou duvidar)
	- Rei: Todos os jogadores trocam de mão com outro jogador seguindo sentido horário
	- Rainha: Indique um naipe que não vale para a aposta, todos os jogadores devem revelar suas cartas do naipe escolhido
	- Valete: Para a aposta, adicione mais um naipe e um novo valor alvo, siga o jogo normalmente (apenas ao aumentar, no máximo uma vez por rodada)
	- Coringa: Apenas conta para qualquer naipe

- O jogo acaba no momento em que um jogador perdeu 3 cartas (abertas na partida), o jogador com menos derrotas é o vencedor
